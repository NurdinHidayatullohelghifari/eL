Pengaturan AI — Groq

EL-GHIFARI memakai Groq melalui backend lokal. API key hanya dibaca oleh server.py; jangan simpan key asli di HTML atau browser.

🚀 Groq AI (backend) Model dikirim ke backend lokal. API key tidak pernah dikirim ke browser.

Koneksi AI memakai API key Groq yang dikonfigurasi pada server.py. Form API key browser di bawah tidak digunakan untuk chat.

Keamanan: menyimpan API key di browser tidak aman untuk aplikasi online publik. Untuk penggunaan produksi, simpan key di backend/server (misalnya variabel lingkungan), jangan di HTML atau JavaScript publik.

Pasang Apps Script dari file Code.gs dan terbitkan sebagai Web App. URL di sini menyambungkan browser admin; agar pengunjung lain ikut tersinkron, masukkan URL deployment pada konstanta PUBLISHED_DRIVE_API_URL di file situs dan terbitkan ulang.
